Page overview

This page reproduces a classic two-column layout without Flexbox or Grid. Every block below is a plain <div>, positioned with float and spaced with margin and padding, the way pages were commonly built before Flexbox and Grid existed.

Layout notes

The sidebar on the left is floated left and given a fixed width. This content block is floated right and takes up the remaining space. The parent container clears both floats afterwards so the footer below sits underneath them instead of climbing up the page.

CSS notes

Each section here has its own background color, padding and border so the structure is visible at a glance: header, in-page nav, sidebar, content and footer are all clearly separated blocks.

Summary

Together these pieces produce the required output: a header on top, a navigation bar below it, a two-column middle section, and a footer pinned to the bottom.
